# REST Assured BDD Project

This project demonstrates API testing using **REST Assured** with the **Behavior-Driven Development (BDD)** approach. It includes end-to-end test scenarios for an e-commerce application, such as user login, adding products, placing orders, viewing order details, and deleting products.

## Features
- **REST Assured** for API testing.
- **Cucumber BDD** for writing test scenarios in Gherkin syntax.
- **TestNG** for test execution and reporting.
- Modular design with reusable components for request and response specifications.
- Singleton pattern for shared state management across scenarios.
